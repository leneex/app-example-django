# Django

Пример приложения [Django](https://www.djangoproject.com/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8000` |
| Путь проверки состояния | `/` |

Railpack видит `manage.py`: ставит зависимости из `requirements.txt`, при запуске применяет
миграции и запускает gunicorn на порту из переменной окружения `PORT` — её передаёт платформа, — а
без неё `8000`. База — SQLite внутри контейнера: при каждом деплое она создаётся заново.

## <a name="dev"></a>Локальный запуск проекта

```bash
# запуск приложения
python3 manage.py runserver
```
