# Django

Example [Django](https://www.djangoproject.com/) app. Django is a high-level Python web framework with a built-in ORM, admin panel and authentication.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `8000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# start the app
python3 manage.py runserver
```
